Términos de Servicio

videogen automated-videos · última actualización 13 septiembre 2026

1. Naturaleza del proyecto

videogen (github.com/yassinebhk/automated-videos) es un pipeline de automatización de contenido de uso personal desarrollado por Yassine Bouhaik. No es un servicio ofrecido a terceros. Estos términos regulan el uso de las APIs de Google (YouTube Data API v3) por parte de este proyecto conforme a los requisitos de Google OAuth Consent.

2. Uso permitido

Este proyecto está autorizado exclusivamente para:

  • Publicar contenido en canales de YouTube propiedad del desarrollador.
  • Consultar estadísticas de esos mismos canales.
  • Gestionar playlists, thumbnails y metadatos de vídeos propios.

3. Contenido generado con IA

Todo el contenido publicado por esta aplicación incluye componentes generados con inteligencia artificial (imágenes vía Pollinations/Pexels, voz vía Edge TTS/Kokoro, guiones asistidos por Gemini/OpenRouter/Groq). Estos elementos son marcados como sintéticos en el metadato del vídeo (containsSyntheticMedia=true) y en la descripción, cumpliendo con la política de YouTube sobre contenido AI-generado (julio 2026) y el EU AI Act (agosto 2026).

4. Veracidad del contenido

El contenido publicado utiliza únicamente datos verificables con fuentes públicas citables. Se incluye disclaimer legal en cada vídeo indicando que no sustituye asesoramiento profesional cuando el tema aplica (fiscal, legal, médico).

5. Cumplimiento API YouTube

El proyecto respeta los YouTube API Services Terms of Service (enlace) y la política de desarrolladores (enlace). No se abusan quotas ni se implementan patrones prohibidos como scraping, spam o manipulación de métricas.

El código es abierto bajo el repositorio público y cualquiera puede consultarlo o adaptarlo bajo su propia responsabilidad.
