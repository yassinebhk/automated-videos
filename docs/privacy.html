Política de Privacidad

videogen automated-videos · última actualización 13 septiembre 2026

1. Quiénes somos

Este proyecto (github.com/yassinebhk/automated-videos) es una aplicación personal desarrollada y operada por Yassine Bouhaik como herramienta de gestión automatizada de canales propios de YouTube, Instagram, Threads, Bluesky, Mastodon y TikTok. No se ofrece a terceros como servicio.

2. Datos que la aplicación accede

La aplicación utiliza APIs de terceros para publicar contenido en canales propiedad del desarrollador. Concretamente:

  • YouTube Data API v3: subir vídeos, actualizar títulos/descripciones/tags, gestionar playlists y consultar estadísticas de los canales propios del desarrollador. Ningún dato de otros usuarios es accedido ni almacenado.
  • Instagram Graph API / Threads API: publicar Reels y posts en cuentas propias.
  • Bluesky / Mastodon / TikTok API: publicar posts en cuentas propias.

3. Datos que se almacenan

La aplicación almacena localmente en el entorno de ejecución (GitHub Actions runners y repositorio privado):

  • Tokens OAuth de los servicios anteriores (refresh_token, client_id, client_secret) como GitHub Secrets encriptados.
  • Ledgers de contenido publicado (identificadores internos de temas ya usados, sin datos personales de terceros).
  • Estadísticas agregadas de los canales propios (subs, views, videos) para monitoreo.

No se recogen ni procesan datos personales de espectadores o seguidores.

4. Compartición de datos

Ningún dato es compartido con terceros. La aplicación no vende, cede ni transfiere ninguna información. Los tokens y credenciales están almacenados exclusivamente en secretos encriptados de GitHub Actions y no son accesibles por otros usuarios ni servicios.

5. Cumplimiento EU AI Act

Todo el contenido generado por esta aplicación se marca explícitamente como creado con asistencia de inteligencia artificial (imagen, voz sintética) en cumplimiento del artículo 50 del EU AI Act (vigor 2 agosto 2026). La marca containsSyntheticMedia=true se aplica en el metadato de cada vídeo subido a YouTube, y un disclaimer visible se añade a la descripción.

6. Derechos del usuario

Al ser una aplicación de uso personal privado (solo el desarrollador la utiliza como propietario de las cuentas), no aplican mecanismos formales de solicitud de derechos GDPR de terceros. Cualquier consulta técnica sobre el código puede dirigirse al repositorio público: Issues del repositorio.
